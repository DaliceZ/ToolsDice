# ToolsDice

ชุดเครื่องมือข้อความ วันเวลา JSON, PDF และ utilities สำหรับนักพัฒนา โดยข้อมูล
ทั้งหมดถูกประมวลผลภายใน browser

## เริ่มต้นใช้งาน

```bash
bun install
bun run dev
```

Frontend เปิดที่ `http://localhost:5173` และ API เปิดที่
`http://localhost:3000` ดูคำสั่งทั้งหมดและข้อกำหนดของโปรเจกต์ได้ใน
[`AGENTS.md`](./AGENTS.md)

## Docker

```bash
docker compose up --build
```

จากนั้นเปิด `http://localhost:8080`
